# Spectator verification

The current client exports to `client/dist/index.html` with `client/build.sh`. It uses Godot 4.7.2 Compatibility, single-threaded WebGL2, no MSAA or shadows, a 65% internal-resolution default and a 50% low mode. Shared immutable meshes batch by asset/material/component; transparent geometry sorts separately. There are no seed/model-name branches. An explicit temporary display box covers asset download/import; authoritative geometry stays on the server. All gameplay remains authoritative on the server.

Independent decoder fixtures pass 27 checks: keyframe/delta/drop, relative centimeter baselines, local-ID reuse, cross-cell membership migration, global coordinates, smallest-three quaternion reconstruction, axes, full state-map replacement and malformed/truncated frames. Interpolation consumes the native welcome's configured `repl_delay_ms`; the fixtures exercise a custom 250ms delay as well as the synthetic 150ms default.

A headless renderer fixture imports a real baked hollow-cylinder GLB, creates 1,000 ordinary synthetic rows, checks one shared batch per mesh, arbitrary term-based color, opacity reclassification and swap-removal. Twelve checks pass, including all three actual GLB LOD imports, distant LOD2 and selected LOD0. Initial creation and the tested updates take approximately 107 ms total in this process; this is CPU setup evidence, not a GPU frame-time claim.

An earlier exported browser renderer fixture used 225 synthetic S6 rows and an actual 26.7 KB baked artifact. Chromium reported SwiftShader through ANGLE, without a hardware GPU. That distance-based LOD run reached the loaded world in 3.50 seconds, imported the GLBs in 15.6 ms, followed/selected an ordinary object, and reported no JavaScript/Godot errors. Shared mesh groups: 2 (distant LOD2 and selected LOD0); fetched geometry/manifest bytes totaled 53,438. GDScript presentation work was about 0–0.4 ms per frame in that static fixture. The full software-rendered frame remained slow: median 66.7 ms, p95 116.6 ms, approximately 14 FPS. An earlier LOD1-only run measured 9 FPS; a concurrent-build LOD run measured 7 FPS. Shared-host variability prevents attributing a precise gain to LOD selection. This does **not** pass the ordinary-laptop smooth-play gate. These historical timings are separate from the current hashed fixture/profile snapshot below.
