# Frozen S11 measurement contract, version 1

The source of truth is original Specs S11, including definitions that produce surprising results. This implementation does not judge whether a world is interesting or change formulas to obtain a favorable comparison. `measure/frozen-v1.json` stores the source definitions and their digest before results are computed. The validation command first writes a timestamped preregistration with that version, frozen expectations, adapter class-table hashes and input provenance.

Every adapter implements `info()` and time-ordered `events()`. Required fields are `t`, `actor`, `type`, `object`; optional metadata follows S11. Identifiers are strings or numbers. The core makes one pass, remembers object/kind metadata and bounded action histories, and reads precomputed authors/oldest when available. It does not reconstruct causal chains. The Ambergris adapter resolves the logged root record ID to its actor in one forward pass and emits `root_actor`; other adapters omit it when no root actor is recorded.

Native S7 `oldest:null` means no recorded non-seed creation time. The adapter omits this absent optional numeric field so the unchanged frozen core applies S11's `created(object)` fallback. Explicit zero remains zero; null result remains a missing result and null authors uses the original inferred-author rule. Failed native model/script submissions retain `of:model|script` even without an assigned ID: they are chosen attempts with no object, and their denied result excludes them from C. A material-rule-created instance remains nonchosen, even when a chosen action caused it.

Implementation details left open by S11 are explicit:

- An entire run is also an aggregation interval. Its active agents have at least 20 chosen events across that interval; each period independently requires 20 in that period. Loop matching retains each agent's preceding history across period boundaries, and attributes a looping event to the period where it occurs.
- A missing result includes absent/null result. Applied or missing results enter C if the class is change. Unknown action types use S11's default change and are counted in a diagnostic. Adapters freeze explicit class tables before computing results.
- Cross-author share uses the literal numerator **all C with at least two non-seed authors**, and denominator **object-bearing C**. It may exceed 1 if an adapter supplies objectless multi-author changes. Those objectless changes are counted separately; the ratio is neither restricted nor clamped. Distinct author pairs are collected across **any event's** author set, not only C, after seed authors are removed.
- No value is clamped to hide a source limitation. Lookback may exceed 1 when a non-seed object predates t0. Median and p90 use linear interpolation between ordered sample values. A seed maker is excluded by the adapter's seed-actor declaration, not by guessing that an old object is seed.
- A kind's first creation is the earliest given/inferred creation of its non-seed objects. Adoption uses the root actor when known, otherwise actor, and the first qualifying use within two period lengths. Objects/kinds first created before the run are history, not novelty created during the run. No hidden chain members are invented from a public log.
- An active agent with no CA has no type distribution. It is excluded from pairs/persistence with a count, rather than assigned a fabricated zero/uniform distribution. Fewer than two remaining agents or CA types makes divergence unavailable. On-role share includes agents with an assigned role and at least one CA; agents with no CA have an undefined share and are counted. `roles` is an optional map from actor ID to its declared list of on-role action types.
- Run persistence averages eligible adjacent-period agent pairs; it does not compare an aggregate distribution with itself. A period's persistence compares it to the immediately preceding period.
- A social-only record has acting share 0, loop rate where activity permits, and unavailable change-based measures. A changes-only record has unavailable acting share. An empty denominator is unavailable, never an invented zero. Gap rate is available only for Ambergris.

`python -m measure ADAPTER --input PATH --output DIRECTORY` writes `report.json` and `periods.csv`. The report names version 1, adapter/provenance, literal scopes, all measures, their counts and per-measure `not_available` reasons. Source errors fail visibly; unsupported source fields are not guessed. `python -m measure.validate` runs the preregistered Wikipedia and Emergence procedures on supplied public records. It records missing/incomplete inputs explicitly instead of manufacturing results. Source-derived adapter checks and small samples are labelled separately from full validation.

Public sources: [Emergence World data and tool catalog](https://github.com/EmergenceAI/Emergence-World), [1F3D9 snapshot contract](https://github.com/onetapstudiogames/1f3d9/blob/main/docs/PUBLIC_SNAPSHOTS.md), [Moltbook-MoltNet schema](https://huggingface.co/datasets/iNLP-Lab/Moltbook-MoltNet), [MediaWiki history dumps](https://dumps.wikimedia.org/other/mediawiki_history/readme.html). Emergence data's repository restricts use to non-commercial research/education; downloaded comparison inputs stay outside distributable source and include that provenance. Wikipedia's full 40-world validation requires either an enumerated complete eligible frame or a verified uniform rejection draw from the complete pinned category universe. The latter records every draw/rejection and replays raw response proofs; it does not claim to enumerate the eligible population. A search/popular-category API subset cannot pass. Both modes use actual 2024 histories and pageviews, with missing inputs and usable weekly pairs explicit. See [the acquisition procedure](wikipedia-acquisition.md).

For an interrupted native writer, `python -m measure.recover --input ORIGINAL.zst --output PREFIX.jsonl` explicitly exports available complete decoded records without modifying the original. It validates every newline-terminated record, fails on malformed middle records, and reports compressed-frame completion, source/output hashes, decoded/retained byte counts and any excluded final fragment. This is a labelled source prefix, never a claim of clean shutdown or reconstructed missing events. Pass its provenance through the Ambergris adapter's optional `source_integrity` option to retain these limits in `report.json`. The actual resident run is documented in `resident-validation.md`.

S7 explicit `changed:false` with absent/null `result` normalizes to `no_effect`; S11’s missing-result default must not turn diagnostic System/seed metadata into applied changes. Chosen action/submission attempts retain their event/class/denominator, and explicit outcomes are preserved. Regression covers ambiguous-anchor System diagnostics as well as seed publication. Frozen core formulas are unchanged.
