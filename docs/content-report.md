# Authored starter content evidence

The starting world is data, actual build123d source and ordinary Luau. `content/start.json` selects seeded/forage and stakes on/off; `content/residents.json` supplies real-model personas and purposes. No native module selects a café object, material spelling, body verb or purpose keyword.

The producer builds 36 model variants from 20 CAD source files. Cache reuse leaves 31 distinct real geometry assets. The seeded plan has 360 roots plus one separately instantiated moving door leaf, 315 relations, 323 ordinary script grants and eight profiles. Forage has 15 roots, six relations and 23 grants. Each selection installs 14 of the 15 Luau sources; the stakes selection chooses one fabrication law. Key fields are file paths only. Native launch creates mode-0600 key files and stores their hashes.

The actual café geometry includes a cut doorway in the dome, a moving leaf excluded from the frame's solid/render ownership, a mezzanine with a matching stair opening, twenty 0.16 m rises, sloped stair rails, deck rails, supports, a hollow tank on a stand, and 300 ordinary non-solid kinematic fish sharing one baked asset. Authored cavity sensors, observer/character constants, material appearance, lighting and zones are explicit asset bindings. Ground spans all starter plots, including forage.

The body implements movement, grasp/release, speech, impact, push, conserved pouring, throwing and seat attachment in Luau using generic primitives. Power, oxygen, threshold responses, charge costs, construction stock, treasury payments and rent are separate scripts. Navigation speed follows authored charge/carry mass and retains the actual mechanical intent ID. Refunds return material, not energy; a source container retains unaccepted pouring remainder. The coarse wood rule changes an indentation property; it does not claim physical mesh deformation. Seat attachment restores Character motion on release; the initial humanoid has no seated animation.

Source/import validation checkpoint:

- Eight Python content tests pass, including real supervisor bakes, source/parameter validation and the actual native fresh-VM Luau declaration validator. Combined gateway/content regression is 16 passing tests.
- All four prepared plans pass the native trusted importer: verified source/hash/canonical parameters, root/part allocation, values, relations, script state, actual permission-derived grants, private profile keys and bootstrap. Seeded import takes about 245–260 ms; forage about 164–169 ms. Those numbers exclude Space collision/nav installation.
- The importer rejects forged grant controls and uninstalled holders. A source `world_rule` flag cannot approve a law. Test-only approval evidence is explicitly labelled as importer authority, not gameplay evidence.
- Generic native physical tests separately exercise real Luau attachment/release, speech classification and a 300-object authorized pose batch.

These are source/import and module-boundary checks.
